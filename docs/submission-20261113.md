# Подготовка к сдаче — 13 ноября 2026

## Что изменено

`BUDGET` — верхний предел конкретного запуска. CLI `--budget` может только уменьшить его; невалидная переменная не скрывается параметром CLI. Нулевой бюджет оставляет локальные решатели доступными. Для онлайн-запуска без переменной требуется явный локальный `--budget`; неявного значения 100 000 больше нет. Источник лимита пишется в `run_start`.

Все запросы, конкурентные резервы и второй проход используют этот фактический бюджет. Межпроцессное продолжение расхода не реализовано: при перезапуске с прежними задачами следует передать остаток. Расход reasoning учитывается как выходной, входной — с весом 0,1; кеш провайдера скидки не даёт.

В образе установлен `HOME=/tmp`. Обычная сборка без `--target` создаёт конкурсный образ; тесты и эталоны находятся в отдельной стадии `bench`. README описывает окружение, оба варианта запуска, сохранение OUT, алгоритмы, нерешаемость, траектории и ограничения. `.env.example` содержит только пустой ключ и явно локальный пример бюджета.

## Архитектура и оставшиеся ограничения

GitHub Actions настроен на нативный Linux amd64: сборка с таймаутом 1000 секунд, полный набор регрессий, smoke обоих способов запуска и проверка размера/содержимого образа. Статус первого запуска будет записан после публикации. Локальный успешный прогон выполнен на Linux arm64. Эмуляция amd64 на Mac не поддерживает seccomp worker; успешную сборку под amd64 нельзя выдавать за полноценную проверку исполнения.

Жюри ещё не запускало решение. Реальный формат дополнительных скрытых тестов и ответы прокси до финала проверить нельзя. Прохождение публичных тестов не доказывает корректность кода на скрытых входах. Не все неоднозначные или нерешаемые задачи распознаются без ошибок. Результаты предыдущих сравнений и их ограничения сохранены в [отчёте последнего эксперимента](recovery-20261113.md).

README явно указывает отличие устаревшего примера команды из документа: необходимо передать актуальный BUDGET, а для общего OUT — также переменную и writable mount. Это соответствует последнему уточнению пользователя; фиксированного лимита 100k нет.
